# 📖 Bộ câu hỏi ôn tập & kiểm tra lý thuyết Điều lệnh CAND

Đây là một ứng dụng web trắc nghiệm giúp cán bộ, chiến sĩ ôn tập và tự kiểm tra kiến thức về Điều lệnh Công an nhân dân. Ứng dụng chạy hoàn toàn **offline**, không cần cài đặt, không cần kết nối internet — chỉ cần tải file HTML về và mở bằng trình duyệt là có thể sử dụng ngay.

## ✨ Tính năng

- Ngân hàng câu hỏi trắc nghiệm bám sát nội dung Điều lệnh CAND
- Chế độ thi có tính giờ, chấm điểm và lưu lịch sử làm bài
- Xem lại chi tiết đáp án đúng/sai sau khi hoàn thành bài thi
- Hỗ trợ nhập thêm câu hỏi từ file CSV
- In / xuất kết quả bài làm
- Không yêu cầu cài đặt, không phụ thuộc máy chủ — mở là dùng được ngay

## 🚀 Cách sử dụng

1. Tải file `.html` trong repo này về máy (hoặc điện thoại)
2. Mở file bằng bất kỳ trình duyệt nào (Chrome, Cốc Cốc, Safari...)
3. Bắt đầu ôn tập

Không cần cài phần mềm, không cần internet sau khi đã tải về.

## ⚠️ Lưu ý

Đây là tài liệu và công cụ **nội bộ**, được biên soạn phục vụ mục đích học tập, ôn luyện. Đây **không phải là sản phẩm hay ấn phẩm chính thức của Bộ Công an**, nội dung câu hỏi mang tính chất tham khảo, hỗ trợ ôn tập.
